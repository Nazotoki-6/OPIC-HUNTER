お題当てゲーム v55

更新日：2026年9月22日

【更新方法】
ZIPを展開し、GitHubリポジトリの同名ファイルをすべて上書きしてください。
ホーム画面に追加済みの端末では、更新後に「最新版があります」が表示されたら「最新版に更新」を押してください。

【v55の主な修正】
・これまで積み重なっていたCSS上書きとインライン/外部コードの重複を整理し、HTML/CSS/JSを一から再構築。
・iPhone縦向きとタブレット横向きの表示を再設計。
・役割表示、カウント、ジャンルを必要最小限に整理。
・正解後の次ラウンド遷移、パス、取り消し、履歴を再点検。
・お題変更は出題側のお題確認時の1回だけに統一。
・PWA更新処理とオフラインキャッシュを整理。
・2000お題を維持。


【v56 BGM追加】
・ゲーム用の控えめなBGMを追加しました。
・外部音源ファイルを使わず、ブラウザのWeb Audioで鳴らすためオフラインでも動作します。
・最初の「ゲーム開始」を押したあとにBGMが始まります（iPhoneの自動再生制限対策）。
・ホーム画面とゲーム画面の「♪ BGM ON/OFF」でいつでも切り替えできます。
・BGM設定は端末に保存されます。


【v57 ジャンル名変更】
・「食べ物」ジャンルを「飲食系」に変更しました。
・ワイン、コーヒー、ジュースなど飲み物のお題でも違和感が出にくくなります。
・対象のお題：275件


【v58 全2000件ジャンル再点検】
・「天気の子」を「アニメ＆漫画」に修正しました。
・アニメ映画、ゲーム、実写映画、場所、企業・ブランドなどの誤分類をまとめて修正しました。
・「旅行＆海外」は国内スポットも含むため「旅行＆スポット」に変更しました。
・曖昧だった「日常」を整理し、「場所・施設」「企業・ブランド」に分けました。
・実写映画用に「映画」ジャンルを追加しました。
・ジャンル変更：603件


【v59 ポケモンのお題を整理】
・ポケモン関連のお題を188件 → 39件に減らしました。
・ピカチュウ、イーブイ、リザードン、ミュウツー、サトシなど知名度の高いお題を中心に残しています。
・減らした149件は、アニメ・漫画、ゲーム、映画、企業・ブランド、旅行スポット、飲食系のお題へ入れ替えました。
・総お題数2000件は維持しています。


【v60 BGM音量アップ】
・BGMの音量をかなり大きくしました。
・メロディーと伴奏の両方を強めています。
・効果音の音量は変更していません。


【v61 緊張感BGM】
・BGMを明るいクイズ風から、緊張感のあるサスペンス調へ変更しました。
・低い脈動音、短い高音、少し不協和なアクセントを加えています。
・テンポも速くして、カウントが進むほど焦りを感じやすい雰囲気にしています。
・音量もv60よりさらに大きくしています。
・効果音の音量はそのままです。


【v62 音楽ジャンル追加】
・「音楽・アーティスト」ジャンルを新設しました。
・歌手、バンド、音楽グループ、作曲家など音楽活動が主軸のお題57件を移動しました。
・宇多田ヒカル、浜崎あゆみ、安室奈美恵、米津玄師、Ado、B'z、Mr.Children、
  サザンオールスターズ、GLAY、L'Arc〜en〜Cielなどが対象です。

・出題側が分かりやすいよう、空欄だった一部のお題に「歌手」「音楽グループ・バンド」も補完しました。
